## 2. Binding technical decisions (do not deviate)

- Node.js ESM, plain modern JavaScript, no TypeScript, no build step. Node ≥ 20.
- `ssh2` npm package for SSH (password auth, one fresh `Client` per command, no pooling).
- `@modelcontextprotocol/sdk` 1.x: `import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js"`,
  `import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js"`.
  `zod` must be installed explicitly (the SDK requires it as peer/dependency).
- VM state = 2 layers: (1) `VBoxManage showvminfo "<name>" --machinereadable` → parse `VMState=`;
  (2) SSH probe `echo ok`. Status-only: NO `VBoxManage startvm` anywhere.
- Command policy = prefix allowlist: allowed iff trimmed command equals a prefix, or starts with
  `<prefix> ` (prefix followed by whitespace). Case-sensitive. No `&&` chain parsing.
- Timeouts: command 30000 ms (env), SSH `readyTimeout` 5000 ms (env), VBoxManage probe 5000 ms (hardcoded).
- Code rules (`.kilo/rules/` apply to all `.mjs` under `src/` and `scripts/`):
  ≤200 lines/file · ≤50 lines per function body · ≤2 indentation levels (extract named helpers) ·
  ≤2 parameters per function (bundle into config/result objects) · no comments · no commented-out
  code · self-documenting names · export only what other modules / the server need ·
  any `if`/`while` condition must be single-section (extract multi-part conditions into named predicates).
- Server logs go to `stderr` ONLY. `stdout` belongs to the MCP protocol. Never print the password.
- Tool failures are returned as `{ isError: true }` results — never thrown out of a tool handler.

### Step 2 — `src/vm-connection-config.mjs`

Env contract (from the global plan):

| Env var | Default | Notes |
|---|---|---|
| `VM_SSH_HOST` | `127.0.0.1` | string |
| `VM_SSH_PORT` | `3022` | positive integer |
| `VM_SSH_USER` | `alpine` | string |
| `VM_SSH_PASSWORD` | — required — | missing/empty ⇒ throw at startup |
| `VM_VBOX_NAME` | `alpine-virt-3.21.2-x86_64` | empty string ⇒ layer-1 skipped later |
| `VM_VBOX_MANAGE_PATH` | `""` (auto-detect) | path override |
| `VM_ALLOWED_PREFIXES` | `docker,sh,apk,ls,cat,ps,df,free,uname,pwd,whoami` | comma-separated |
| `VM_COMMAND_TIMEOUT_MS` | `30000` | positive integer |
| `VM_SSH_READY_TIMEOUT_MS` | `5000` | positive integer |

API (exactly this shape):

```js
export const createVmConnectionConfig = (environment = process.env) => { /* … */ };
```

- Single exported factory; no default-consumable singletons (callers pass `process.env` or a mock).
- Parse every numeric field via one named helper `parsePositiveInteger(value, variableName)`
  → throws `Error("<name> must be a positive integer, received '<value>'")` otherwise.
- Missing `VM_SSH_PASSWORD` (empty/undefined) → `Error("VM_SSH_PASSWORD is required — set it in the MCP environment configuration")`.
- `allowedPrefixes` = raw string split on `,`, trimmed, empty strings filtered out.
- `vboxManagePath` stays the raw string (may be `""` — the probe decides resolution).
- Return a deeply frozen plain object: `{ sshHost, sshPort, sshUser, sshPassword, vboxName,
  vboxManagePath, allowedPrefixes, commandTimeoutMs, sshReadyTimeoutMs }` (`Object.freeze`).

### Step 3 — `src/command-policy.mjs`

```js
const matchesAllowedPrefix = (command, prefix) => command === prefix || command.startsWith(`${prefix} `);

const hasAllowedPrefix = (command, allowedPrefixes) =>
  command.length > 0 && allowedPrefixes.some(prefix => matchesAllowedPrefix(command, prefix));

export const isCommandAllowed = (command, allowedPrefixes) => hasAllowedPrefix(command.trim(), allowedPrefixes);
```

(Keeps every boolean gate single-section via the `hasAllowedPrefix` predicate.)
Boundary strings are hardcoded here, NOT inside policy: message building lives in `vm-tools.mjs`.

### Step 4 — `src/vm-state-probe.mjs`

```js
import { execFile } from "node:child_process";
import { existsSync } from "node:fs";
import { promisify } from "node:util";
const execFileAsync = promisify(execFile);

export const VBOX_PROBE_TIMEOUT_MS = 5000;
export const resolveVBoxManagePath = (config) => { /* … */ };
export const queryVmState = async (config) => { /* … */ };
```

- `resolveVBoxManagePath(config)`: (a) `config.vboxManagePath` if non-empty → use it; else
  (b) `C:\Program Files\Oracle\VirtualBox\VBoxManage.exe` if `existsSync` → use it; else
  (c) `"VBoxManage"` (PATH fallback). Verify precedence with exactly this order.
- `queryVmState(config)`:
  1. Build args `["showvminfo", config.vboxName, "--machinereadable"]` with `execFileAsync(path,
     args, { timeout: VBOX_PROBE_TIMEOUT_MS, windowsHide: true })`.
  2. Parse stdout: find the first line whose lowercase form starts with `vmstate=`; slice
     8 chars, strip `"` quotes and trim → state token.
  3. Map token: `running` → `"running"`; one of `poweroff|saved|aborted|paused` → `"poweroff"`;
     anything else → `"unknown"`.
  4. Any error (missing exe, VM name unknown, timeout) → return `"unknown"`. NEVER throw.
  (Split probing/parsing into ≥2 small named helpers to respect the ≤50-line/≤2-depth rules.)

### Step 5 — `src/ssh-command-runner.mjs`

```js
import { Client } from "ssh2";

export const runSshCommand = (config, command) => { /* … returns Promise<{stdout, stderr, exitCode}> */ };
export const probeSsh = async (config) => { /* … returns boolean */ };
```

- `runSshCommand(config, command)` — Promise wrapper around one fresh `Client`:
  1. Connect args: `{ host: config.sshHost, port: config.sshPort, username: config.sshUser,
     password: config.sshPassword, readyTimeout: config.sshReadyTimeoutMs }`.
  2. `on("ready")` → `connection.exec(command, { pty: false }, (error, stream) => …)`;
     accumulate `stdout`/`stderr` from stream `data`/`close`(code, signal) events;
     on close → `connection.end()`; resolve `{ stdout, stderr, exitCode: code === null ? 1 : code }`.
  3. `on("error")` → `connection.end()`; reject with mapped message:
     `code === "ECONNREFUSED"` → `SSH not reachable on <host>:<port>`, else
     `SSH connection failed: <original message>`.
  4. Command timeout: a `setTimeout(config.commandTimeoutMs)` guard → on fire `connection.end()`
     and reject `Error("Command timed out after <ms> ms")`; clear the timer on settle.
- `probeSsh(config)`: `try { const outcome = await runSshCommand(config, "echo ok");
  return outcome.exitCode === 0 && outcome.stdout.trim() === "ok"; } catch { return false; }`
  (wrap the `&&` in a named helper if the single-section rule applies — e.g.
  `const isCleanEcho = (outcome) => …`). If rejected → `false`.

### Step 6 — `src/vm-tools.mjs`

Exports (factories close over the frozen config so each tool has ≤1 handler parameter):

```js
export const createVmStatusTool = (config) => { … };
export const createVmRunCommandTool = (config) => { … };
```

Result shape everywhere: `{ content: [{ type: "text", text }], isError }` — build via one shared
local helper `textResult(text, isError = false)`.

**`vm_status` handler** (no arguments):
- `vmState = await queryVmState(config)` (also when `config.vboxName` is empty → treat as
  `"unknown"`, skip layer 1).
- `vmState === "poweroff"` → skip SSH probe; message
  `VM '<vboxName>' is not running — start it in VirtualBox first.`, `sshReachable: false`.
- `vmState === "running"` → `sshReachable = await probeSsh(config)`; `true` →
  `SSH reachable on <host>:<port> — ready for commands.` ; `false` →
  `VM '<vboxName>' is running but SSH is not reachable on <host>:<port>.`
- `vmState === "unknown"` → `sshReachable = false`; message
  `Could not determine VM state — VBoxManage probe failed or was skipped.`
- Text includes a small status summary line, e.g. `vmState: running | sshReachable: true`, then
  the message (exact format left to the implementer's local detail: keep it two short lines).

**`vm_run_command` handler** (arguments `{ command: string, timeoutMs?: number }`), gated in this
exact order, each failure gate returns `textResult(msg, true)`:
1. Status gate — `await queryVmState(config)`; if not `"running"` →
   `VM not running — run vm_status for details and start the VM in VirtualBox first.`
2. SSH gate — `if (!(await probeSsh(config)))` → `SSH not reachable on <host>:<port>.`
3. Policy gate — `isCommandAllowed(command, config.allowedPrefixes)`; if false →
   `Command rejected: '<command>' does not match allowed prefixes [<list joined by ", ">].`
4. Execute — derive `{ …config, commandTimeoutMs: args.timeoutMs ?? config.commandTimeoutMs }`
   (shallow spread copy), `const outcome = await runSshCommand(derivedConfig, args.command)`
   wrapped in `try/catch`: catch → `textResult('Command failed after start: <error message>', true)`.
5. Report — text lines:
   `exit code: <outcome.exitCode>`, then `stdout:` + block, then `stderr:` + block;
   truncate STDOUT/STDERR at 10000 chars each via a named helper (`… [truncated]` suffix).
   `isError: true` iff `outcome.exitCode !== 0`.

### Step 8 — `scripts/smoke-test.mjs`

Standalone ESM script; spawner + JSON-RPC line protocol;**no** npm deps beyond Node built-ins
(`node:child_process`, `node:process`, `node:util` if needed).

Behavior (binding):
1. Spawn `process.execPath` with args `["src/server.mjs"]`, `cwd` = repo root (derive via
   `process.cwd()`, script must be run by `npm run smoke-test` from the repo root), env
   `{ ...process.env, VM_SSH_PASSWORD: process.env.VM_SSH_PASSWORD ?? "alpine",
   VM_SSH_READY_TIMEOUT_MS: process.env.VM_SSH_READY_TIMEOUT_MS ?? "4000" }`.
2. Send newline-delimited JSON-RPC over `child.stdin` (write each line + `\n`):

```js
const initializeRequest = { jsonrpc: "2.0", id: 1, method: "initialize", params: {
  protocolVersion: "2025-06-18", capabilities: {},
  clientInfo: { name: "vm-ssh-mcp-smoke", version: "0.1.0" } } };
const initializedNotification = { jsonrpc: "2.0", method: "notifications/initialized" };
const toolsListRequest = { jsonrpc: "2.0", id: 2, method: "tools/list" };
const statusCallRequest = { jsonrpc: "2.0", id: 3, method: "tools/call",
  params: { name: "vm_status", arguments: {} } };
```

   `initialize` FIRST, then the notification, then `tools/list`, then the `vm_status` call —
   in this order (MCP handshake order).
3. Buffer `child.stdout` text; split on `/\r?\n/`; keep a remainder for the last partial line;
   `JSON.parse` each complete line. Record: `initialize` result (has `serverInfo.name
   === "vm-ssh-mcp"`), `tools/list` result (names include `vm_status` AND `vm_run_command`),
   `tools/call` result (`content[0].text` non-empty; with VM OFF it must mention not running).
4. On receiving id 3 (or after a 20 s overall guard timer): print PASS/FAIL summary to
   `process.stdout` of the SCRIPT (the script's own output, not the server's), kill
   (`child.kill()`), and `process.exit(0)` on all three checks ok, else exit 1.
   Guard timer: `setTimeout` 20000 → kill child, print `SMOKE TEST TIMED OUT`, exit 1.
5. In `finally`, always kill the child. Ignore harmless write-EPIPE on kill.
